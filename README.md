# KOSPI Momentum Screener

Web dashboard for the KOSPI rolling-window momentum breakout screener.  
Engineered by **Moon Quixote**.

---

## Overview

A clean, minimalist web interface designed to visualize momentum breakout candidates before they enter the Pre-Flight Breakout (PFB) phase.

* **Matches**: Stocks crossing rolling volume and price expansion thresholds.
* **Raw History**: Daily closing prices over the evaluation window.
* **Normalized View**: Price action indexed to 100 from the start of the base week.

---

## Screening Criteria

1. **Volume Surge**: Evaluation 7-day average volume exceeds base week average volume $\times$ configured multiplier (default: $2.0\times$).
2. **Price Expansion**: Evaluation window end close exceeds base week average close $\times$ configured multiplier (default: $1.2\times$).
3. **Continuous Uptrend**: Closing prices rise continuously over the final 3 trading sessions ($t-2 < t-1 < t$).

---

## Tech Stack & Data

* **Frontend**: Vanilla HTML5, CSS3, JavaScript (no external frameworks or build steps).
* **Design Philosophy**: Monochromatic Apple-spec product page aesthetic.
* **Data Source**: Reads static JSON output (`data/results.json`) generated by `screener.py`.
